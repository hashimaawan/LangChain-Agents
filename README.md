#  LangChain Agents 

This repository contains modular examples and utilities for building intelligent agents using **LangChain**.

LangChain agents use large language models to **decide actions**, **use tools**, and **reason** step-by-step to complete complex tasks.

Example:
> Agent: "To answer this, I need to search the web."  
> → Uses SearchTool  
> → Analyzes response  
> → Returns final answer
